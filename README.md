English
Welcome to my trading system!

When you run the program, you will be taken directly to the main menu where you can choose to create an account and then log in.

Once you are logged in, you will enter the user menu where you have several different options. Through menu option 1, you can add an item with a short description regarding its condition and other relevant information worth sharing. After that, you will have an item that you can start trading with against other users’ items. Before you choose to start trading, you can go to menu option 2 to see everyone’s items, including your own, to check if you find something you like. In menu option 3, you can view only your own items. Then, in menu option 4, you can send a trade request. You select from the list by entering the number corresponding to the item you want to trade for. If you select yourself, the system will say “you cannot trade with yourself,” and if you enter a number that exceeds the number of users with items in the list, the system will say “invalid input.” When you enter a correct number, you proceed to choose which of your own items you want to offer if you have more than one. After that, you will receive a message that your request has been sent.

The other user who logs in will then see one or more notifications in menu option 6 if they have one or more trade requests waiting for a response.

Back to the first user: after sending a request, they can go to menu option 5 to see which requests they have sent. A numbered list of sent requests will appear. It shows who you sent the request to, which item you offered, and which item you wish to receive. Finally, you will see the status of the trade.

Returning to the second user: they now have a notification next to menu option 6 that looks like this (1). This means the user has a trade waiting for a response. The user chooses to enter menu option 6 and then sees a list of trades, each numbered along with information about who the request is from and which items the trade involves. You select the number corresponding to a request and then respond with “y” (=yes) or “n” (=no). With a “y,” the user is informed that the trade has been completed, and the items change ownership. With an “n,” the entire trade is declined, the items return to their original owners, and the status is no longer pending. Regardless of whether the answer is “y” or “n,” the status changes to completed, which the user can see in menu option 7.

In menu option 7, you get more information about a trade. Here you can see which two users have exchanged two different items.

Svenska
Välkommen till mitt trading system!

Vid körning av programmet kommer du direkt till huvudmenyn där du kan välja att skapa ett konto för att sedan logga in. 

När du väl är inloggad kommer du till användarens meny där du har flera oika menyval. Genom menyval 1 lägger du till ett objekt med en kort beskrivning som avser skick och annan dylik information som är värd att förmedla. Därefter har du ett objekt du kan börja byta med mot andra användares objekt. Innan du väljer att börja byta så kan du gå in på menyval 2 för att se allas objekt inklusive dina egna för att se om hur hittar något du gillar. På menyval 3 kan du se enbart dina egna objekt. Därefter går du in på menyval 4 där du kan skicka en förfrågan om ett byte. Du kan välja i listan genom att skriva in ett nummer som du vill utföra bytet med. Väljer du dig själv så kommer systemet att säga "du kan inte byta med dig själv" och om du skriver en siffra som överskrider antalet användare med objekt i listan så kommer systemet att säga "felaktig inmatning". När du skriver in korrekt siffra går du vidare till att välja vilket av dina objekt du vill byta om du skulle ha fler än ett objekt. Därefter skickas ett meddelande till dig att din förfrågan har blivit skickad.

Den andra användaren som loggar in får då upp en eller flera notifikationer i menyvalet 6 om användaren har en eller flera notifikationer som väntar på ett svar.

Tillbaka till första användaren som efter en skickad förfrågan kan gå in på menyval 5 för att se vilka förfrågningar som användaren har skickat. Då kommer det upp en lista med skickade förfrågningar som är numererade. Det står vem du har skickat en förfrågan till och vilket objekt du erbjuder samt vilket objekt du önskar att få till dig. Slutligen får du information om bytets status. 

Om vi återgår till den andra användaren så har denne nu fått en notifikation bredvid sitt menyval 6 som ser ut såhär (1). Detta betyder att användaren har ett byte som väntar på svar. Användaren väljer att gå in i menyval 6 och får sedan upp en lista med byten och varje byte är numererad tillsammans med information om vem förfrågningen är från samt vilka objekt bytet avser. Du väljer numret som avser en förfrågning för att sedan svara "y" (=yes) eller "n" (=no). Vid ett "y" får användaren information om att bytet är genomfört och det som händer är att objekten byter ägare. Vid ett "n" avslås hela bytet och objekten återvänder till sina ägare och status slutar sedan vara pending. Oavsett om svaret är "y" eller "n" så övergår statusen till completed. Vilket användaren kan se vid menyval 7.

I menyval 7 får du mer information gällande ett byte. Här kan du se vilka två användare som har bytt två olika objekt.
